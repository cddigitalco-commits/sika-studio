SIKA STUDIO — Remplacement des vidéos

1. Renommez vos 3 fichiers vidéo exactement : video-1.mp4, video-2.mp4, video-3.mp4
2. Placez-les dans le dossier assets/videos/ (remplacez les fichiers s'il y en a déjà).
3. Ne changez pas ces noms de fichiers : le site les appelle directement par ces noms dans index.html.
4. Format recommandé : MP4, vertical 9:16, taille raisonnable pour un chargement rapide sur mobile.
5. Tant qu'une vidéo video-X.mp4 est absente ou illisible, le site affiche automatiquement l'image de couverture correspondante (poster-X.svg) à sa place — aucune action requise de votre part dans ce cas.

Les fichiers poster-1.svg, poster-2.svg, poster-3.svg et les logos ne doivent pas être renommés, sauf à mettre aussi à jour les références correspondantes dans index.html.
