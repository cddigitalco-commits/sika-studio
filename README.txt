# Sika Studio — site V1

## Mise en ligne gratuite avec GitHub Pages

1. Va sur https://github.com et crée un compte.
2. Clique sur "New repository".
3. Nom du dépôt : `sika-studio`
4. Mets le dépôt en Public.
5. Envoie les fichiers `index.html`, `style.css`, `script.js` et le dossier `assets`.
6. Dans le dépôt : Settings → Pages.
7. Dans "Build and deployment", choisis "Deploy from a branch".
8. Sélectionne la branche `main` et le dossier `/ (root)`.
9. Enregistre.
10. GitHub donnera l'adresse de ton site.

## IMPORTANT : WhatsApp

## Ajouter tes vidéos

Place tes vidéos dans le dossier `assets`.

La V1 contient actuellement des emplacements visuels de démonstration. On pourra ensuite remplacer ces éléments par ton vrai portfolio.

- Vidéos : 15 à 60 secondes
- Starter : 1 correction, livraison 48 h
- Growth : 1 correction, livraison 48 h
- Scale : 3 corrections, livraison 72 h
- Le client fournit une photo du produit + sa description + les informations nécessaires
- Sika Studio choisit l’avatar IA
- Paiement : 50 % à la commande, 50 % à la livraison
